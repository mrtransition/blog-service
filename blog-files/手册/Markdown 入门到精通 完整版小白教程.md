# 一、Markdown 核心认知（必看）

## 1\.1 什么是 Markdown？

Markdown 是一种**轻量级标记语言**，简单来说：**用极简的符号，实现美观的文档排版**。

它区别于 Word 手动点按钮排版，全程靠简单符号语法，写完即可自动渲染成规整格式，兼容所有平台（笔记软件、博客、代码社区、办公文档）。

## 1\.2 为什么要学 Markdown？

- **极简高效**：不用鼠标点排版，专注内容写作，告别格式错乱

- **全网通用**：所有主流笔记、写作、代码平台均支持，一次编写、处处使用

- **格式统一**：不会出现 Word 跨设备格式乱码、排版错位问题

- **轻量化**：无冗余代码，文件体积小，打开速度快

## 1\.3 核心特点

语法**大小写不敏感、容错率高**，小白无需死记硬背，常用语法仅20种左右，零基础快速上手。

# 二、基础语法（入门必学，90%场景够用）

基础语法是日常写作、记笔记、写文档的核心，熟练掌握即可满足绝大多数需求。

## 2\.1 标题语法（层级排版）

通过 `\#` 号实现标题层级，**\# 越少，标题字号越大**，共6级标题。

### 语法格式

```Plain Text
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 渲染效果

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题

### 小白小贴士

\# 后面必须加**空格**，否则无法识别为标题；日常写作常用1\-4级标题即可。

## 2\.2 文本样式（字体美化）

用于突出重点文字，包含加粗、斜体、删除线、下划线四种常用样式。

|样式|语法格式|渲染效果|
|---|---|---|
|斜体|`\*文字\*`|*文字*|
|加粗|`\*\*文字\*\*`|**文字**|
|加粗斜体|`\*\*\*文字\*\*\*`|***文字***|
|删除线|`\~\~文字\~\~`|~~文字~~|

## 2\.3 段落与换行

### 段落

直接输入文字即为普通段落，段落之间**空一行**实现分段，排版更整洁。

### 换行

方式1：段落末尾输入**两个空格**，再回车换行（标准语法）

方式2：直接回车（大部分编辑器兼容，小白首选）

## 2\.4 分割线

用于分割不同内容模块，页面更清晰。

### 语法格式

`\-\-\-` 或 `\*\*\*`（单独一行输入）

### 渲染效果

## 2\.5 列表语法（高频使用）

### 无序列表（无序号）

语法：`\- 内容` / `\* 内容`（符号后必须加空格）

```Plain Text
- 第一项内容
- 第二项内容
- 第三项内容
```

渲染效果：

- 第一项内容

- 第二项内容

- 第三项内容

### 有序列表（带序号）

语法：`数字\. 内容`（点后必须加空格）

```Plain Text
1. 第一项内容
2. 第二项内容
3. 第三项内容
```

渲染效果：

1. 第一项内容

2. 第二项内容

3. 第三项内容

### 嵌套列表

回车后**缩进2个空格**，即可实现列表嵌套

```Plain Text
- 一级列表
  - 二级嵌套列表
    - 三级嵌套列表
```

渲染效果：

- 一级列表
        

    - 二级嵌套列表
                

        - 三级嵌套列表

```

### 渲染效果

> 
> 

## 2\.7 行内代码

用于标记关键词、命令、代码单词，适配笔记、技术文档。

### 语法格式

\`\` 包裹内容：`\`这里是代码内容\``

### 渲染效果

# 三、进阶语法（精通必备，提升文档质感）

进阶语法适用于正式文档、技术笔记、博客创作、工作报告等场景。

## 3\.1 代码块（多语言支持）

用于展示完整代码片段，支持语法高亮、代码分行。

### 语法格式

三个反引号 \`\`\` \+ 代码语言名称，结尾三个反引号闭合

```Plain Text
```python
# Python示例代码
def hello():
    print("Hello Markdown")
```
```

### 渲染效果

```python
# Python示例代码
def hello():
    print("Hello Markdown")
```

### 常用语言标识

python、java、js、html、css、sql、bash、json

## 3\.2 表格语法（数据整理）

用于制作规整表格，展示数据、参数、对比信息。

### 语法格式

```Plain Text
| 表头1 | 表头2 | 表头3 |
| ----- | ----- | ----- |
| 内容1 | 内容2 | 内容3 |
| 内容4 | 内容5 | 内容6 |
```

### 渲染效果

|表头1|表头2|表头3|
|---|---|---|
|内容1|内容2|内容3|
|内容4|内容5|内容6|

### 表格对齐技巧

- 默认：居中对齐

- `:\-\-\-` 左对齐

- `\-\-\-:` 右对齐

- `:\-\-\-:` 居中对齐

## 3\.3 超链接

插入网页链接、资源链接，支持自定义链接文字。

### 语法格式

`\[链接显示文字\]\(链接地址\)`

### 示例

[百度官网](https://www.baidu.com)

## 3\.4 图片插入

图片语法和链接类似，**前方多一个感叹号**。

### 语法格式

`\!\[图片备注文字\]\(图片地址/本地图片路径\)`

### 小贴士

网络图片直接粘贴链接，本地图片拖拽即可（主流编辑器均支持）。

## 3\.5 任务清单（待办事项）

用于制作工作计划、学习清单、打卡任务。

### 语法格式

```Plain Text
- [x] 已完成任务
- [ ] 未完成任务
```

### 渲染效果

* [x] 已完成任务

* [ ] 未完成任务

## 3\.6 脚注（文档注释）

用于文末备注、释义、来源标注，适合正式文档。

### 语法格式

```Plain Text
正文内容[^1]

[^1]: 这里是脚注注释内容
```

### 渲染效果

Markdown 是极简排版语言\[^1\]

这里是脚注注释内容

# 四、高阶技巧（精通核心，小众实用）

## 4\.1 转义字符

当需要展示 `\# \* \- \`` 等符号本身时，在符号前加 `\\` 转义，避免被识别为语法。

示例：`\\\# 这不是标题` → 渲染为：\# 这不是标题

## 4\.2 锚点跳转

实现文档内跳转，适合长文档目录导航。

语法：`\[跳转到对应标题\]\(\#标题文字\)`

## 4\.3 高亮块/提示框

主流编辑器支持，用于突出重点提示、注意事项。

```Plain Text
::: tip 提示
这是温馨提示内容
:::

::: warning 注意
这是警告注意内容
:::
```

# 五、小白快速上手规范（避坑指南）

## 5\.1 必守格式规范

1. 所有语法符号（\#、\-、\*、\&gt;）**后面必须加空格**，90%格式错误都是因为缺空格

2. 标题、列表、段落之间空一行，排版更美观

3. 代码块、表格单独占一行，不要和文字同行

## 5\.2 新手高频误区

- 不要堆砌过多样式，一篇文档只用1\-3种重点样式，简洁为主

- 不要混用多级标题，严格按照层级使用（二级→三级，不越级）

- 复杂表格尽量简化，Markdown 不适合超复杂表格排版
