正则函数总览

Oracle 11g 提供了 5 个核心正则表达式函数，遵循 POSIX 标准，支持 Perl 风格元字符。 所有函数均支持 match_parameter 选项（如 'i' 忽略大小写，'m' 多行模式）。
REGEXP_LIKE 条件判断 WHERE 子句
REGEXP_LIKE(source_char, pattern [, match_param])

在 WHERE 中判断字符串是否匹配正则，返回 TRUE / FALSE。

-- 查找以 'A' 开头，后跟数字的员工
SELECT employee_name
FROM employees
WHERE REGEXP_LIKE(employee_name, '^A[0-9]');
→ 匹配： 'A1' , 'A9'  |  不匹配：'B1', 'A10'（第二位非数字）
-- 忽略大小写，查找包含 'oracle' 或 'ORACLE' 的邮箱
SELECT email
FROM users
WHERE REGEXP_LIKE(email, 'oracle', 'i');
→ 匹配： 'oracle@xx.com', 'MyORACLE@yy.com' ...
REGEXP_SUBSTR 提取子串 返回 VARCHAR2
REGEXP_SUBSTR(source_char, pattern [, position [, occurrence [, match_param]]])

从源字符串中提取匹配正则的第一个（或第 N 个）子串。

-- 提取第一个连续的数字
SELECT REGEXP_SUBSTR('订单号: 2024-008, 金额: 1299.50', '[0-9]+') AS 第一组数字
FROM dual;
→ 结果： '2024'
-- 提取第二个由字母和数字组成的单词
SELECT REGEXP_SUBSTR('商品 SKU: AB12-C3, 库存: 50', '[A-Z0-9]+', 1, 2) AS 第二个匹配
FROM dual;
→ 结果： 'C3'
REGEXP_INSTR 定位索引 返回 NUMBER
REGEXP_INSTR(source_char, pattern [, position [, occurrence [, return_opt [, match_param]]]])

返回匹配子串的起始（或结束）位置。若 return_opt = 0 返回起始位置，1 返回结束位置+1。

-- 查找第一个 'oracle' 出现的位置（忽略大小写）
SELECT REGEXP_INSTR('Welcome to Oracle 11g, oracle is powerful.', 'oracle', 1, 1, 0, 'i') AS 起始位置
FROM dual;
→ 结果： 12   （'O' 在 "Oracle" 中的位置）
-- 返回第二个 'a' 之后的结束位置
SELECT REGEXP_INSTR('banana', 'a', 1, 2, 1) AS 结束位置
FROM dual;
→ 结果： 4   （第二个 'a' 在索引3，结束位置为4）
REGEXP_REPLACE 替换 返回 VARCHAR2
REGEXP_REPLACE(source_char, pattern [, replace_string [, position [, occurrence [, match_param]]]])

使用正则匹配并替换，支持反向引用 \1、\2 等。

-- 将日期格式从 'YYYY-MM-DD' 替换为 'DD/MM/YYYY'
SELECT REGEXP_REPLACE('2025-08-25', '(\d{4})-(\d{2})-(\d{2})', '\3/\2/\1') AS 新日期
FROM dual;
→ 结果： '25/08/2025'
-- 移除所有数字字符
SELECT REGEXP_REPLACE('AB12CD34EF', '[0-9]', '') AS 去数字
FROM dual;
→ 结果： 'ABCDEF'
REGEXP_COUNT 计数 返回 NUMBER
REGEXP_COUNT(source_char, pattern [, position [, match_param]])

返回正则模式在源字符串中出现的次数（非重叠）。

-- 统计 'a' 或 'A' 的出现次数（忽略大小写）
SELECT REGEXP_COUNT('Alabama', 'a', 1, 'i') AS 计数
FROM dual;
→ 结果： 4   （A l a b a m a → 4个 a/A）
-- 统计连续数字组的个数
SELECT REGEXP_COUNT('2024-08-25 15:30:45', '\d+') AS 数字组数
FROM dual;
→ 结果： 6   （2024, 08, 25, 15, 30, 45）

常用元字符 & 模式

Oracle 11g 正则表达式基于 POSIX 扩展，同时支持 Perl 风格简写。下表列出了最常用的元字符及示例。
.
匹配任意单个字符（除换行）
*
零次或多次匹配前一个字符
+
一次或多次匹配前一个字符
?
零次或一次匹配前一个字符
{m,n}
匹配 m 到 n 次
^
匹配字符串开头
$
匹配字符串结尾
[abc]
匹配 a、b 或 c
[^abc]
匹配除 a、b、c 外的任意字符
[a-z]
匹配小写字母
[A-Z]
匹配大写字母
[0-9]
匹配数字
\d
等价于 [0-9]
\D
非数字
\w
单词字符 [A-Za-z0-9_]
\W
非单词字符
\s
空白字符（空格、制表等）
\S
非空白字符
|
逻辑或，如 a|b
(...)
分组，用于捕获和反向引用
\1, \2 ...
反向引用分组内容
\b
单词边界
\B
非单词边界

match_parameter 常用选项

  • 'i' 忽略大小写
  • 'm' 多行模式（^ 和 $ 匹配行首/尾）
  • 'c' 区分大小写（默认）
  • 'n' 使 . 匹配换行符
  • 'x' 忽略空白和注释

综合实战示例

将多个函数组合使用，解决真实数据清洗与提取问题。

提取并格式化电话号码

-- 从混杂文本中提取 (xxx) xxx-xxxx 格式的电话，并转为 xxx-xxx-xxxx
WITH raw AS (
  SELECT '联系: (123) 456-7890 或 987-654-3210' AS txt FROM dual
)
SELECT
  REGEXP_SUBSTR(txt, '\(\d{3}\)\s*\d{3}-\d{4}', 1, 1) AS 原始,
  REGEXP_REPLACE(
    REGEXP_SUBSTR(txt, '\(\d{3}\)\s*\d{3}-\d{4}', 1, 1),
    '\((\d{3})\)\s*(\d{3})-(\d{4})', '\1-\2-\3'
  ) AS 格式化
FROM raw;
→ 原始： (123) 456-7890   |   格式化： 123-456-7890

验证并提取邮箱域名

-- 从用户输入中提取邮箱域名（@ 之后的部分）
SELECT
  email,
  REGEXP_SUBSTR(email, '@([^@]+)$', 1, 1, 'i') AS 域名
FROM (
  SELECT 'user@oracle.com' AS email FROM dual
  UNION ALL
  SELECT 'admin@company.co.uk' FROM dual
) t;
→ 结果： @oracle.com , @company.co.uk
使用 '@([^@]+)$' 匹配 @ 符号后到字符串结尾的非 @ 字符
